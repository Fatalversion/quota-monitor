## The icons

The provider marks in [ui/panel.js](ui/panel.js) are **not** vendor logo files.
No brand asset is vendored into this repository. Each one is simple geometry we
authored, drawn on a 24x24 grid, evoking the product it identifies:

| Provider | What is drawn |
| --- | --- |
| Claude Code | An eight-ray burst |
| Codex | A six-fold rosette of three rounded capsules |
| GitHub Copilot | A rounded visor |
| Cursor | A pointer |
| Devin | A simple bot head |

This is deliberate on two counts.

**Licensing.** A vendor's logo is their property and is not ours to
sublicense. Shipping one inside an MIT-licensed repository would imply we had
granted rights we do not hold, which would make the LICENSE file wrong. Our
drawings are covered by the MIT licence; the marks they evoke are not.

**Fidelity.** These render at 22 pixels. An accurate trace of a detailed logo
turns to mush at that size, so a mark that is simple on purpose reads better
than a faithful one reproduced badly.

They are approximations and are meant to be. If a vendor would prefer a
different treatment, or none, open an issue and we will change it.
